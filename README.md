# 🎙️ TTS READER — Natural, Fast, Beautiful Text‑to‑Speech ✨

```💡 A modern, responsive, cross‑device Text‑to‑Speech Reader built for iPad, mobile, and desktop screens. Designed for creators, learners, and professionals who want natural voices, smooth playback, recording, and export — all inside a single elegant web app 💡.```

## 🌈 Features at a Glance
    💠 Natural Voices — Choose between US 🇺🇸 and UK 🇬🇧 voice sets
    
    🔷 Responsive Layout — Fully optimized for iPad, iPhone, and all screen sizes
    
    🔶 Unlimited Text Input — Paste as much text as you want
    
    💎 Playback Controls — Play, pause, stop, resume
    
    🔹 Recording Engine — Capture system audio and screen
    
    🔸 Speed Control — Adjust reading speed smoothly
    
    🔴 Voice Selection — Pick your preferred reader with flag icons
    
    ✦ Clean UI — Minimal, modern, touch‑friendly interface

## 📱 Responsive Across All Devices
### The app automatically adapts to:
    🦄 iPad (portrait + landscape)
    
    🐥 iPhone (all sizes)
    
    🐙 Android phones
    
    🖥️ Desktop browsers
    
    📜 Large monitors

## Your TTS Reader includes a full media bar:
    ▶️ Play — Start reading
    
    ⏸️ Pause — Freeze playback
    
    ⏹️ Stop — Reset to beginning
    
    🎙️ Record — Capture system audio
    
    🔁 Resume — Continue from last position
    
    🔊 Speed Slider — Slow or fast reading
